KONTEKS APLIKASI (WAJIB DIPAHAMI)

Tujuan aplikasi:
Aplikasi digunakan untuk menampilkan data indikator strategis dari Web API BPS dalam bentuk card indikator dan halaman detail dengan grafik historis.

Struktur Data API (Contoh Nyata)

Data utama berupa:

meta → informasi rilis (provinsi, bulan, tahun)
cards[] → daftar indikator

Setiap card memiliki:

id
category
title
type (single / multi)
data
period

Contoh variasi:

Single value → angka utama
Multi value → beberapa breakdown (contoh inflasi)
Dengan perubahan (trend) → ada direction, change_value
Tanpa perubahan → hanya value
Kebutuhan Tampilan
Halaman Utama (Dashboard)
Menampilkan list card indikator
Bisa dikelompokkan berdasarkan kategori
Menampilkan:
Title
Nilai utama
Satuan
Periode
Indikator naik/turun (jika ada)
Halaman Detail
Menampilkan:
Metadata indikator
Deskripsi (jika ada)
Grafik historis (line chart)
Data historis:
Tahunan / Triwulan / Bulanan (tergantung data API)
